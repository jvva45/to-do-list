# 🧩 Sistema de Controle de Tarefas

Sistema web de gerenciamento de tarefas desenvolvido como desafio técnico para a vaga de Programador PHP.

O objetivo do projeto é demonstrar domínio técnico em PHP puro, MySQL, Bootstrap, jQuery, organização de código, boas práticas e documentação clara.

---

## 🎯 Funcionalidades

- Cadastro de usuários com senha criptografada
- Login e logout de usuários
- Dashboard individual de tarefas
- Criação, edição, exclusão e conclusão de tarefas
- Busca por título
- Filtro por status (pendente/concluída)
- Interações dinâmicas via AJAX (sem recarregar a página)
- Interface responsiva com Bootstrap 5

---

## 🧱 Tecnologias Utilizadas

- PHP 8+
- MySQL
- Bootstrap 5
- jQuery
- AJAX
- Git

> Nenhum framework PHP foi utilizado, conforme exigido no desafio.
